# Rhytmo

Desenvolva um e-commerce premium para uma marca de streetwear autoral. O objetivo é criar uma experiência que pareça uma mistura entre uma galeria digital, um editorial de moda e uma loja online. O site deve transmitir exclusividade, tecnologia, simplicidade e direção artística.

O resultado final deve lembrar a linguagem visual de:

• hextermina.com
• dongfengfive.com
• bugsex.nyc
• happy99.online

Não copie nenhum layout. Apenas absorva a identidade visual, o ritmo, as animações, o uso da tipografia, os espaços em branco, a composição e a experiência geral.

IDENTIDADE

Visual extremamente limpo.

Editorial.

Experimental.

Minimalista.

Frutiger Aero contemporâneo.

Atmosfera premium.

Direção artística forte.

Pouquíssimos elementos na tela.

Muito espaço negativo.

Nada genérico.

Nada parecido com um template de Shopify.

PALETA

Utilize exclusivamente a paleta de cores enviada.

Não utilize nenhuma outra cor.

Distribuição:

• Branco como fundo principal.

• Cinzas apenas para superfícies e divisões.

• Verde para CTAs e estados ativos.

• Azul para links, elementos interativos e detalhes.

• Rosa apenas em pequenos destaques.

Nunca utilizar preto absoluto.

TIPOGRAFIA

Fonte grotesca moderna.

Inter, Helvetica Neue, Geist ou Satoshi.

Peso Bold ou ExtraBold.

Títulos enormes.

Pouco texto.

Hierarquia clara.

Espaçamento perfeito.

A tipografia deve ser um elemento gráfico do layout.

LAYOUT

Landing Page

Hero ocupando praticamente toda a primeira tela.

Logo da marca.

Imagem principal utilizando os assets enviados.

Título enorme.

Botão "SHOP".

Ao clicar, a página deve fazer scroll suave até os produtos.

Não criar uma landing page longa.

Depois do Hero já começam os produtos.

HEADER

Header transparente.

Fica sólido ao rolar.

Logo pequena.

Carrinho no canto direito.

Sem menu tradicional.

Sem categorias.

Sem barra de pesquisa.

Sem links desnecessários.

PRODUTOS

Cards grandes.

Imagem dominante.

Nome.

Botão Add to Cart.

Hover sofisticado.

Animações discretas.

Nada de bordas pesadas.

Nada de sombras exageradas.

CARRINHO

Drawer lateral.

Abre suavemente.

Atualiza valores em tempo real.

Quantidade.

Remover item.

Subtotal.

Botão Checkout.

CHECKOUT

Interface limpa.

Campos grandes.

Resumo do pedido.

Botão principal.

Sem distrações.

FRUTIGER AERO

Aplicar de forma moderna.

Utilizar apenas:

gradientes suaves

formas orgânicas

brilhos discretos

esferas translúcidas

camadas leves

reflexos suaves

vidro apenas em pequenos detalhes

blur leve

luz difusa

Nunca deixar o layout carregado.

ANIMAÇÕES

As animações devem ser um dos principais diferenciais.

Scroll extremamente suave.

Fade.

Scale.

Parallax leve.

Texto aparecendo conforme o scroll.

Imagens com movimento sutil.

Microinterações refinadas.

Transições em torno de 250 ms.

Nada exagerado.

RESPONSIVIDADE

Tablet perfeito.

Performance acima de tudo.

ASSETS

Vou enviar:

• Logo oficial

• Elementos gráficos

• Fotografias dos produtos

Todos esses arquivos devem ser utilizados como identidade visual principal.

Nunca substituir por imagens genéricas.

QUALIDADE

Cada detalhe deve transmitir uma marca internacional.

O site deve parecer desenvolvido por um estúdio criativo especializado em moda, com acabamento equivalente ao de campanhas editoriais e experiências digitais de marcas independentes de alto nível.

Priorize composição, ritmo visual, tipografia, animações e direção de arte acima de efeitos chamativos. O resultado deve parecer uma peça de design, não apenas uma loja virtual.
