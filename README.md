# Rhytmo

A premium, minigame-inspired e-commerce experience — products discovered as
floating objects in an explorable digital universe, with a robot companion
guiding the journey. Backend commerce is powered by Shopify.

## Development

You need Node.js (or Bun) installed.

```sh
git clone <this-repository-url>
cd <repository-name>
bun install   # or: npm i
bun dev       # or: npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Shopify (commerce backend)
